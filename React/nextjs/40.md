# 组件使用

所有组件都是服务端组件， `use client` 是用来划清打包边界的，声明了 `use client` 的都会打包到客户端的代码中， 当在 `use client` 声明的组件中引入了服务端组件,服务端组件也会被当成是客户端组件。 

客户端组件通过以 props 的方式使用服务端组件， 服务端组件不会被打包到客户端组件代码中, 以children 的方式使用， 会被打包的客户端组件代码中。使用时需要考虑组件是否使用了第三方组件代码。控制打包的bundle 大小。 


## 使用注意

'use client' 声明的客户端组件顶层不能使用 `async/await` 语法糖。原因是客户端组件渲染是同步的。
