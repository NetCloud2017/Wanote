## change mode

修改文件夹和文件权限

    格式 chmod [用户][+-=][权限] [文件]

```bash
# 给所有者增加执行权限
chmod u+x app.sh
# 移除其他用户写权限
chmod o-w test.txt
# 所有人都拥有读写执行
chmod a=rwx run.sh
# 所有者读写，组只读，其他人只读
chmod u=rw,g=r,o=r index.js

```

## 字段解析

Linux 每个文件对三类用户区分权限:

    u user：文件所有者（当前创建人，这里是 root）
    g group：同用户组账号
    o other：其他所有外部用户
    a all：全部三类用户（u+g+o）

权限:

    r read 读权限：查看文件内容 / 列出文件夹
    w write 写权限：修改、删除、新增文件
    x execute 执行权限：运行脚本 / 进入文件夹

## 数字权限写法

r=4，w=2，x=1，每类用户数字相加

    数字	权限组合	含义
    7	rwx (4+2+1)	读写执行
    6	rw- (4+2)	读写，不可执行
    5	r-x (4+1)	读 + 执行，不可写
    4	r-- (4)	仅可读
    0	---	无任何权限

```bash
# 文件通用：所有者读写，其余只读（644）
chmod 644 .env
# 脚本/程序：所有者读写执行，其余只读 + 执行（755）
chmod 755 start.sh
# 完全开放（不推荐生产，仅本地测试）
chmod 777 public/


```
**关键参数**

    # 文件夹递归授权（-R 递归子文件子目录）
    chmod -R 755 /var/www/notes

    --reference=文件：复制另一个文件的权限
    chmod --reference=index.js app.ts
